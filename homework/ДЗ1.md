# Домашнее задание №1. От бизнес-требований к физической модели
## Вариант №2. Служба доставки еды (Food Delivery)

## Задание 1. Концептуальная модель

1. «Пользователи могут просматривать рестораны, их меню, делать заказы».
2. «У каждого ресторана есть меню с блюдами».
3. «В заказе может быть несколько блюд с указанием количества».
4. «Курьеры доставляют заказы».
5. «Пользователи могут оставлять отзывы о ресторанах и доставке».

| Сущность 1 | Сущность 2 | Тип связи | Обоснование |
| --- | --- | --- | --- |
| User | Order | 1 : N | Один пользователь может сделать много заказов; каждый заказ принадлежит одному пользователю |
| Restaurant | Dish | 1 : N | У одного ресторана много блюд; блюдо принадлежит одному ресторану |
| Order | OrderItem | 1 : N | Один заказ включает несколько позиций; каждая позиция относится к одному заказу |
| Dish | OrderItem | 1 : N | Одно блюдо может встречаться во множестве позиций разных заказов |
| Courier | Order | 1 : N | Один курьер доставляет много заказов; каждый заказ доставляет один курьер |
| User | Review | 1 : N | Один пользователь может написать много отзывов |
| Order | Review | 1 : 1 | На один заказ — один отзыв (охватывает оценку ресторана и доставки) |

## Задание 2. Логическая модель

| Сущность | Атрибуты | Первичный ключ (PK) | Внешние ключи (FK) |
| --- | --- | --- | --- |
| User | `user_id`, `full_name`, `email`, `phone` | `user_id` | — |
| Restaurant | `restaurant_id`, `name`, `address`, `rating` | `restaurant_id` | — |
| Courier | `courier_id`, `full_name`, `phone`, `rating`, `is_active` | `courier_id` | — |
| Dish | `dish_id`, `restaurant_id`, `name`, `description`, `current_price` | `dish_id` | `restaurant_id` → Restaurant |
| Order | `order_id`, `user_id`, `restaurant_id`, `courier_id`, `total_amount`, `status`, `created_at` | `order_id` | `user_id` → User, `restaurant_id` → Restaurant, `courier_id` → Courier |
| OrderItem | `order_id`, `dish_id`, `quantity`, `price_at_order` | `(order_id, dish_id)` | `order_id` → Order, `dish_id` → Dish |
| Review | `review_id`, `order_id`, `user_id`, `restaurant_id`, `courier_id`, `rating`, `comment`, `created_at` | `review_id` | `order_id` → Order, `user_id` → User, `restaurant_id` → Restaurant, `courier_id` → Courier |

## Задание 4. Частые запросы

1. Поиск качественных ресторанов: «Показать список ресторанов в указанном районе (по адресу), имеющих средний рейтинг выше 4.5, отсортированных по убыванию рейтинга».
2. Аналитика популярности: «Вывести топ-10 самых заказываемых блюд за последнюю неделю с указанием общего количества проданных порций и выручки по каждому блюду».
3. Детализация чека: «Получить полную информацию по конкретному заказу: данные пользователя, название ресторана, список заказанных блюд с их количеством и ценой на момент заказа, имя курьера и текущий статус доставки».
4. Финансовый отчет: «Рассчитать общую выручку каждого ресторана за текущий календарный месяц только по успешно доставленным заказам».
5. Рейтинг исполнителей: «Найти всех активных курьеров, которые выполнили (статус 'delivered') более 100 заказов и имеют средний рейтинг не ниже 4.8, для начисления им бонусов».
